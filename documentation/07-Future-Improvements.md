# Future Improvements

This project will continue to expand as additional enterprise technologies are implemented.

Planned improvements include:

- Configure DNS
- Configure DHCP
- Create Organisational Units (OUs)
- Create Active Directory users
- Create Security Groups
- Configure Group Policy Objects (GPOs)
- Join a Windows 11 Enterprise client to the domain
- Configure shared folders
- Configure NTFS permissions
- Configure roaming profiles
- Create login scripts
- Perform Active Directory administration tasks
- Automate administrative tasks using PowerShell

The repository will continue to be updated as new features are implemented.
