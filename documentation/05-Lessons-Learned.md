# Lessons Learned

This project provided practical experience with deploying and configuring a Microsoft Active Directory environment using Windows Server 2025.

Throughout the implementation, I developed a better understanding of enterprise Windows Server administration, Active Directory Domain Services (AD DS), networking concepts and virtualisation using VMware Workstation Pro.

The project also reinforced the importance of planning changes, validating configurations before deployment, documenting technical work and troubleshooting issues encountered during implementation.

One notable issue occurred during the Domain Controller promotion process, where the prerequisite validation failed because the local Administrator account password did not meet Windows password complexity requirements. Resolving this issue highlighted the importance of understanding Windows security policies and verifying prerequisites before deployment.

Overall, the project strengthened both my technical knowledge and my ability to document complex configuration tasks clearly and methodically.
