# Introduction

## Overview

This project documents the design and implementation of a Microsoft Active Directory Home Lab using Windows Server 2025 and VMware Workstation Pro.

The objective of this lab is to simulate a real-world enterprise environment while developing practical skills in Windows Server administration, Active Directory, networking and IT support.

The project follows the complete deployment of a Windows Server 2025 Domain Controller, beginning with the creation of a virtual machine and progressing through the installation and configuration of Active Directory Domain Services (AD DS). Each stage is documented with explanations and screenshots to demonstrate the work completed and the knowledge gained throughout the project.

---

## Project Objectives

The objectives of this project are to:

- Build a Windows Server 2025 virtual machine.
- Configure a secure Windows Server environment.
- Deploy Active Directory Domain Services (AD DS).
- Configure DNS and DHCP services.
- Create and manage Active Directory users and groups.
- Join Windows 11 Enterprise clients to the domain.
- Configure Group Policy Objects (GPOs).
- Simulate an enterprise network environment.
- Develop practical Windows Server administration and IT Support skills.
